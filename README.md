## Open source we ship

### 🕳️ [god-of-the-void](https://github.com/CHAOSX-SPACE/god-of-the-void) — a Claude Code skill with a body

Most skills are a prompt. This one has **persistent memory that survives every
session**, a search that costs ~0 tokens, an **errarium** where every bug is
stored with its *cause, solution and lesson* — and a **local dashboard** to see
it all.

```sh
curl -fsSL https://raw.githubusercontent.com/CHAOSX-SPACE/god-of-the-void/main/install.sh | bash
```

**One command.** It asks where your memory should live, and forges the rest:
database, 16 organs, 5 hooks, permissions, tray app and dashboard.

<sub>Zero dependencies · 1,650 automated tests · MIT</sub>
